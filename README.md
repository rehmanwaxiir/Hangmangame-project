
# Python Hangman Game

A simple word-guessing game developed using Python. The player guesses one letter at a time to find the hidden word before running out of attempts.

## Features

- Random word selection
- Letter-by-letter guessing
- Tracks incorrect guesses
- Displays the remaining attempts
- Shows win or lose messages
- Beginner-friendly command-line interface

## How to Play

1. Run the Python program.
2. The game selects a random word.
3. Guess one letter at a time.
4. Correct guesses reveal the letter in the word.
5. Incorrect guesses reduce your remaining attempts.
6. Guess the complete word before your attempts run out to win.

## Requirements

- Python 3
- No external libraries required

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code or a terminal.
3. Run the following command:

   ```bash
   hangman_game.py
   ```

   On Windows, you can also try:

   ```bash
   py hangman_game.py
   ```
